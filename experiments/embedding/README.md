# Embedding Model Experiments

This directory documents embedding model evaluation
for the Enterprise AI Knowledge Assistant.

## Objective

Select an embedding model suitable for production
enterprise document retrieval.

## Evaluation Criteria

- Recall@1
- Recall@3
- Recall@5
- MRR
- Embedding dimension
- Inference latency
- Resource requirements

## Candidate Models

- all-MiniLM-L6-v2
- BGE-small
- BGE-base

## Results

Results are generated from the Colab benchmark notebook.

## Selection

The production embedding model will be selected
after evaluating the complete enterprise benchmark.
